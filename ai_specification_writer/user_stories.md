# TaskFlow – User Stories

## User Story 1 – Create Tasks

As a university student, I want to create tasks for my assignments so that I can organise my study workload.

**Acceptance Criteria:**
- Students can create a task by entering a title and optional description.
- Newly created tasks appear in the task list.
- Tasks are saved and remain available after logging back in.

**Priority:** MVP

## User Story 2 – Edit Tasks

As a university student, I want to edit existing tasks so that I can update assignment information when requirements change.

**Acceptance Criteria:**
- Students can edit a task's title, description, and deadline.
- Updated information is saved successfully.
- Changes are displayed immediately in the task list.

**Priority:** MVP

## User Story 3 – Delete Tasks

As a university student, I want to delete tasks that are no longer needed so that my task list stays organised.

**Acceptance Criteria:**
- Students can select a task to delete.
- The system asks for confirmation before deletion.
- Deleted tasks no longer appear in the task list.

**Priority:** MVP

## User Story 4 – Set Deadlines and Priorities

As a university student, I want to assign deadlines and priority levels to tasks so that I can focus on urgent assignments.

**Acceptance Criteria:**
- Students can assign a due date to each task.
- Students can select a priority level of High, Medium, or Low.
- The task list displays each task's deadline and priority.

**Priority:** MVP

## User Story 5 – Organise Tasks by Course

As a university student, I want to group tasks by course so that I can manage assignments from different subjects separately.

**Acceptance Criteria:**
- Students can create course categories.
- Students can assign tasks to a course.
- Students can filter tasks to view a specific course.

**Priority:** High

## User Story 6 – Track Task Progress

As a university student, I want to update the progress status of my tasks so that I can see what I have completed and what remains.

**Acceptance Criteria:**
- Students can change a task's status to To Do, In Progress, or Done.
- Status changes are saved automatically.
- Tasks can be viewed based on their current status.

**Priority:** MVP

## User Story 7 – Receive Deadline Reminders

As a university student, I want to receive reminders before assignment deadlines so that I can avoid missing submissions.

**Acceptance Criteria:**
- Students can enable or disable deadline reminders.
- The system sends a reminder 24 hours before a task's due date.
- Students do not receive reminders for completed tasks.

**Priority:** High

## User Story 8 – Share Group Projects

As a student working on a group project, I want to share a project task list with my teammates so that we can collaborate on assignments.

**Acceptance Criteria:**
- Students can create a shared project.
- Students can invite other users to join the project.
- Project members can view the shared task list.

**Priority:** Medium

## User Story 9 – Assign Group Tasks

As a student working on a group project, I want to assign tasks to team members so that everyone knows their responsibilities.

**Acceptance Criteria:**
- Project members can assign tasks to other members of the same project.
- Assigned tasks display the responsible member's name.
- Team members can view tasks assigned to them.

**Priority:** Medium

## User Story 10 – View Overall Workload

As a university student, I want to view all my upcoming tasks in one dashboard so that I can plan my study time effectively.

**Acceptance Criteria:**
- The dashboard displays tasks from all courses and projects.
- Students can sort tasks by upcoming deadlines.
- Completed tasks are visually distinguished from incomplete tasks.

**Priority:** High
