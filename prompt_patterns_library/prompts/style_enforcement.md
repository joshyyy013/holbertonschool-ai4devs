# Style Enforcement Prompt Template

**Category**: Code Quality

**Role**: Code Reviewer

**Task**: Rewrite the code to follow the supplied style rules. Preserve its behaviour and public interfaces.

**Input Placeholder**:
- Language: [LANGUAGE]
- Code: [CODE_BLOCK]
- Style rules: [STYLE_RULES]

**Expected Output Format**:
1. A fenced code block containing the revised code.
2. A list of style corrections and the rule each correction follows.
