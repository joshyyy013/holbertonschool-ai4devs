# README Creation Prompt Template

**Category**: Documentation

**Role**: Developer Documentation Writer

**Task**: Write a README that helps a new developer understand, install, run, and test the project. Use the supplied commands and details. Flag missing information rather than inventing commands.

**Input Placeholder**:
- Project name and purpose: [PROJECT_NAME_AND_PURPOSE]
- Project structure: [PROJECT_STRUCTURE]
- Dependencies and versions: [DEPENDENCIES]
- Setup requirements: [SETUP_REQUIREMENTS]
- Verified installation, run, and test commands: [VERIFIED_COMMANDS]

**Expected Output Format**:
Return Markdown README content with these sections:
1. Project overview.
2. Requirements.
3. Installation and configuration.
4. Usage.
5. Testing.
6. Project structure.

Mark any missing information clearly.
