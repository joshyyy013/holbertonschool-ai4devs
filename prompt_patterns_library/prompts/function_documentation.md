# Function Documentation Prompt Template

**Category**: Documentation

**Role**: Technical Writer

**Task**: Document the supplied function in the requested format. Describe only behaviour supported by the code or specification. Identify unclear behaviour instead of inventing it.

**Input Placeholder**:
- Language: [LANGUAGE]
- Function: [FUNCTION_CODE]
- Required format, such as docstring or Javadoc: [DOCUMENTATION_FORMAT]
- Behaviour specification, if available: [BEHAVIOUR_SPECIFICATION]

**Expected Output Format**:
1. A fenced code block containing the documentation in the requested format, covering purpose, parameters, return value, and errors where applicable.
2. Any questions about unclear behaviour.
