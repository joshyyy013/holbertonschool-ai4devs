# Integration Test Design Prompt Template

**Category**: Testing

**Role**: Integration Test Engineer

**Task**: Design tests for the complete workflow across the supplied components. Cover successful interactions and relevant failure paths. Use the available environment and make each scenario repeatable.

**Input Placeholder**:
- Workflow: [WORKFLOW_DESCRIPTION]
- Components and interfaces: [COMPONENTS_AND_INTERFACES]
- Expected behaviour and failure rules: [EXPECTED_BEHAVIOUR]
- Available test environment and tools: [TEST_ENVIRONMENT]
- Test data and constraints: [TEST_DATA_AND_CONSTRAINTS]

**Expected Output Format**:
For each scenario, provide:
1. Scenario name and purpose.
2. Setup and test data.
3. Actions or requests.
4. Expected results and assertions.
5. Cleanup steps.

State which components are real or simulated and any limits of the test environment.
