# Code Explanation Prompt Template

**Category**: Documentation

**Role**: Programming Tutor

**Task**: Explain the supplied code at the reader's experience level. Describe its purpose, execution flow, and key concepts, defining unfamiliar terms and using a small example where helpful.

**Input Placeholder**:
- Language: [LANGUAGE]
- Code: [CODE_BLOCK]
- Reader's experience level: [EXPERIENCE_LEVEL]
- Specific question or focus: [QUESTION_OR_FOCUS]

**Expected Output Format**:
1. A short plain-language overview.
2. A numbered walkthrough of the execution flow.
3. Explanations of key concepts.
4. A small example showing input and output where applicable.
